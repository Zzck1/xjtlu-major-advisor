# 专业资料与示例内容审阅

版本：0.1.0-rc1｜审阅日期：2026-09-18。  
类型：由未编写专业资料和示例的代理进行内容审阅；包含实际本地数据比较与人工语义检查。**这不是平台实测，不是学生咨询运行测试，也不代表全量资料的逐句人工验收。**

## 审阅范围与方法

实际读取 `maintenance/catalog.json`、专业 Markdown 档案、`work/school-cache/extracted.json` 与对应原始 HTML。原始 HTML 为本次开发抓取缓存；核对六个样本的 SHA-256，均与 catalog 保存的散列相同。HTML 的课程区以 `h2.title` 区分方向、`h4` 区分年级、`h5` 区分核心／可选、`li.accordion_list` 提取课程名称，再分别与提取 JSON、catalog 和 Markdown 比较。比较保留重复出现的课程，不将同名条目自行合并。

人工检查包括：学院及学习地点、专业与方向关系、概览和职业摘要是否有原文支持、相近项目比较是否夸大差异、学习要求分析是否由词面误判。另通读两份示例会话与报告，逐项核对学生证据及报告所引用的课程。

缓存是本工作区的维护中间材料，不是学生运行依赖。公开原始来源和核查记录见[来源登记](../xjtlu-major-advisor/references/source-register.json)；课程仍以正式培养方案为准。本次没有获取 e-Bridge 内部资料或课程模块的学分、考核和先修细则。

## 发现、处置和复核

| 编号 | 发现与影响 | 原始证据 | 当前结果 |
| --- | --- | --- | --- |
| CR01 | 金融商务英语最初只登记“英语”父项，遗漏金融经济／商务管理内部方向；总课程表可能被误读为两个方向人人同修。 | `english-and-business.html` 概览；初始缓存第 873、931、940 行明确两个商科方向可任选其一。 | **已修复并复核**：catalog 和档案新增 `--finance-economics`、`--business-management` 子编号，写明官网合列课程，不能认定所有方向课程每位学生同修。 |
| CR02 | AI 阅读写作分析以“自然语言处理／决策、计算和语言”为依据，土木以“设计语言与人工智能导论”为依据；技术课程名称中的“语言”不能单独支持文字表达要求。 | 两份初始档案“阅读写作与表达”段；对照原文课程性质及知识技能段。 | **已修复并复核**：两份档案改为课名不足以单独判断，不再将上述课程当作文字表达的直接证据。仍可按适用英语教学说明与实际任务继续了解学生。 |
| CR03 | 金融商务英语与国际商务的比较最初只举国际商务“中文3／4／5”，可能使读者误以为中文课程是该项目的主要区别。 | 国际商务原表还含日语、西班牙语、跨境管理、管理研究中的定量研究方法；其概览强调国际商务与第二外语。 | **已修复并复核**：相互比较均改为跨境管理、管理研究中的定量研究方法及西班牙语课程；国际商务档案明确多语言及级别是合列范围，不能理解为每位学生同时全部修读。 |
| CR04 | 汉学与中国学已经列出三个方向，但初始档案未保留“方向并非必选”及满足学分后毕业选择方向的说明。 | `china-studies.html` 第 941 行明确可灵活选课，方向并非必选。 | **已修复并复核**：方向口径说明已经保留“方向并非必选”、先探索、满足学分后选择以及不选方向而灵活选课的边界。 |
| CR05 | 六样本统一写“来源发布日期未明确”，但 HTML 的 JSON-LD 实际有 `datePublished`、`dateModified`。正文不显示日期与机器可读元数据无日期是不同情况。 | 例如 AI：2025-06-05 发布、2026-08-31 修改；汉学：2022-10-09 发布、2026-09-11 修改；金融商务英语：2022-10-09 发布、2026-06-15 修改，均为站点元数据日期。 | **专业资料已修复并复核**：档案及来源登记区分正文未标日期和站点元数据时间。进一步实际检查全 52 条 catalog 元数据与原始 HTML 的 WebPage 字段，52/52 一致；仍明确元数据不是课程生效学年。 |

CR01–CR05 修复后均重新读取实际生成的档案和 catalog，而非仅接受“已修复”的描述。全量 52 条日期核对属于结构字段检查，不等同于对 52 份档案做了逐句语义审阅。另核对[覆盖记录](coverage.md)已保留课程重复、核心／选修交叠及名称／路径差异，不静默删课或解释为每位学生全部同修。

## 相近项目比较的核查

六个主样本所引用的双方课程名称均能在对应详情页的课程表中找到。土木与建筑学、应用化学与材料科学、汉学与国际事务及国际关系的例子能够提供学习内容差异的初步线索；会计与经济金融、AI 与数据科学的比较也保留了课程交集与方向限制，没有声称“对方未列名称，所以绝不教该内容”。

这些段落主要是公开课程线索，尚不足以给出必选比例、难度、实际工作量或职业能力强弱排序。金融商务英语／国际商务最初的代表性问题按 CR03 已修复。课程名称比较不应替代完整档案和学生经历的匹配。

## 两份虚构示例的实际审阅

通读 [示例 A 会话](../examples/evidence-rich/conversation.md) 与 [报告](../examples/evidence-rich/report.md)，以及 [示例 B 会话](../examples/early-stop/conversation.md) 与 [报告](../examples/early-stop/report.md)。它们均明确是开发者编写的行为示例，没有冒充真实学生或运行记录。

两报告涉及另外五份档案：计算机科学与技术、数据科学与大数据技术、信息与计算科学、传播学、信息管理与信息系统。独立从这五页 HTML 提取课程，分别检查 34、29、30、53、45 条课程出现项，与缓存提取结果一致；再核对报告实际提到的 **30 个“课程名称＋年级”主张，30/30 找到一致依据**，这些被引用的具体课程均在官网对应年级的核心课程栏。报告 B 没有将传播学各方向选修拼成人人必修方案。

示例 A、B 均有七个报告部分、至少三项具体行动、明确资格缺口及资料时间限制。本次没有发现必须修改的学生证据或课程年级错误。两示例第 7 节原有“页面发布日期未明确／发布日期未注明”用语已随 CR05 同步修复，**重新读取后确认**均明确指正文未标日期，并说明站点元数据发布／修改时间见来源登记、不是课程生效学年。

独立模型运行的原始 SC05 及前向测试输出包含修复前的日期用语。[模型评阅记录](model-review.md)已将其标为历史输出的非阻塞备注，并保留实际响应，未为使记录看似通过而改写原始运行证据。当前资料和手工示例的日期字段修复不等于重新执行了这些历史测试。

## 审阅结论与界限

六个分散专业的课程转录和身份字段通过本次抽查；两份示例的 30 项课程／年级主张与学生证据对应未发现错误。审阅确实发现了内部方向遗漏、课程名称引起的分析误判、比较例子代表性及元数据日期记录问题，已逐项报告，并只对实际复核的修复记为完成。

本记录不覆盖所有 52 份档案的逐句语义审查，也不确认任何真实学生的专业资格；没有完整校内门槛、对应届别培养方案或四个平台的真实操作证据。整体交付仍应保持“候选版，存在明确待办”，不能从 52 个页面读取成功或本次抽样一致推出所有事实与平台能力均验收完成。
