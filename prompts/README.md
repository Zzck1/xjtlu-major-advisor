# 通用提示词使用说明

版本：0.1.2-rc1｜2026-09-19。

## 最简用法

1. 将 [完整总控提示词](../xjtlu-major-advisor/assets/universal-prompt.md) 代码框中的全文复制到支持长文本指令的AI对话，或该工具提供的角色／项目指令位置。具体容量及能力以当前平台为准。
2. 同时提供Skill资料，至少先让模型读到核心规则、开场初筛、录取表、专业索引和资格规则；形成候选后再补完整专业档案。只粘提示词不会让模型自动获得所有专业资料。
3. 输入“开始选专业咨询”。模型开场只问太仓意愿并等待回答；随后逐轮补入学年份和招生身份，课程只在具体候选需要时核对。
4. 后续按需复制 [16个场景指令](../xjtlu-major-advisor/assets/prompt-commands.md)，可比较候选、改答、提前出报告、生成Word或保存续聊摘要。

已有原生Skill能力的工具，使用最新版Skill并输入启动语即可，不必反复粘贴完整总控提示词。普通聊天环境用提示词搭配上传资料；联网、长期记忆和Word附件能力依赖宿主工具，提示词不能保证平台具备这些功能。

## 需要一起提供的资料

- [SKILL.md](../xjtlu-major-advisor/SKILL.md) 及其中的相对路径资料。
- [开场与初筛](../xjtlu-major-advisor/references/intake-screening.md)：太仓意愿开场、学期区别、校区筛选。
- [录取要求及校区转写表](../xjtlu-major-advisor/references/admission-table.md)：53条记录及原工作表定位，另有同目录JSON保留原文与空值。
- [全专业索引](../xjtlu-major-advisor/references/major-index.md) 及候选对应完整档案；不能只上传索引就要求正式推荐。
- 有适用届别的正式录取／选专业细则时补充，成绩只提供相关部分。

如平台不支持目录上传，可使用分发目录的豆包资料包：先提供核心规则与简表；然后按领域索引提供候选详细组。这里只说明文件组织方式，不保证任一平台支持ZIP直接安装。

## 当前资料边界

官网专业档案仍为2026-09-18核查的0.1.0-rc1版；新增T01为2026-09-19收到的用户参考表，没有注明发布单位、适用届别或身份，也没有具体录取分数线。表格C列是第二学期课程，不能当作第一学期先修门槛。开场只问太仓意愿，具体课程和成绩在候选需要时再核对。

默认最后交付三份Word，分别是决策与候选、画像与两个候选差异、就业与验证行动及信息边界。不能生成附件时应给三组完整正文并说明限制。提示词及示例指令均未预填任何真实学生的成绩、经历或偏好。
