# 西浦选专业顾问

规则与交付版本：`0.1.1-rc1`｜专业资料版本：`0.1.0-rc1`｜2026-09-18｜**候选版，存在明确待办**。

面向西交利物浦大学尚未确定本科专业的大一学生。完成对应平台的安装或资料上传后，输入：

> 开始选专业咨询

顾问会每次问一个主要问题，通常用约 15–25 分钟了解你的兴趣、实际学习经历、选择资格和优先事项。你可以说“不知道”“跳过”“修改上一条”，也可以随时说“现在先出报告”。已有咨询摘要时，粘贴或上传后说“继续上次”。

默认得到三份独立可编辑的 Word：①决策结论与适配候选；②你的选择画像与两个重点候选的差异；③就业探索、接下来的验证行动与信息边界。三份包含来源、支持与反对理由、补足要求及至少三项验证行动。已确认可选的专业才会进入正式推荐排序。若个人资格还不清楚，报告会给出不分名次的适配候选和需确认的条件，不把它们称为正式首选。

## 准备什么

知道入学年份和适用身份即可开始。之后可能需要了解相关课程、必要成绩或对应届别的学校政策；不知道时可以跳过。无需提供姓名、学号、电话、身份证号或完整成绩单。上传材料请自行遮盖无关个人信息。

不需要安装 Python、Node，不需要配置 API Key。咨询使用你所选平台的账号、模型与额度。各平台支持的入口和文件能力不同，安装方式以交付包中对应平台说明为准；同一个 ZIP 并非已在所有平台实测可导入。

## 资料及当前边界

- [专业索引](references/major-index.md) 提供候选入口、稳定编号和详细档案链接；学校目录不代表每位学生已符合全部专业的选择条件。
- [资格规则](references/eligibility.md) 区分已确认可选、待核实和已确认不符合。具体校内课程、成绩门槛及不同届别适用性，以可核对的政策为准。
- [职业资料索引](references/career/index.md) 提供有来源的探索信息；专业与职业之间不是保证关系。
- 本地资料记录核查日期，课程、政策、岗位和升学要求可能变化。正式决定前按报告中的待核实事项完成确认；联网不可用时仍可进行基于本地资料的咨询。

本包提供可审阅的核心规则、资料及输出模板。是否已在某平台完成真实操作测试，应查看完整交付中的平台验证记录。文档核验、静态检查和虚构场景模拟不能替代真实平台测试。

## 如何继续使用报告

可以直接说“比较这两个专业”“按兴趣优先重新比较”“我补充了课程成绩，更新资格”“检查这条来源”或“给我下一步探索清单”。修改只影响相关判断，已回答的信息不会要求重新填写。

支持 Word 输出的平台会把三份 `.docx` 保存在你的任务目录并分别提供下载链接；不支持的平台按相同三组提供完整可复制正文，并说明附件能力限制。续聊摘要仅按需另行提供。个人回答不会成为本 Skill 的公共资料。宿主平台自身对聊天的保存方式由其设置和政策决定，Skill 不具备删除平台历史或改变平台数据策略的能力。
