# TraeWork CN 使用说明

资料版本：0.1.1-rc1｜核验日期：2026-09-18｜状态：已确认本机产品身份；仅文档核验，安装及完整咨询待用户环境验证。

## 已确认的是哪个产品

本机桌面快捷方式名称为 **TraeWork CN**。只读查看其目标程序及随安装包提供的产品元信息，得到：`nameAlias=TraeWork CN`、`appVersion=0.1.67`、`tronBuildVersion=2.3.85573`，构建时间 2026-09-16；程序保留 `TRAE SOLO CN` 名称。此适配面向 **TraeWork CN 桌面版**，没有把它当成 TraeCode IDE。未读取历史对话、个人账号或令牌，未实际导入技能。

## 学生如何安装和开始

1. 在自己的 TraeWork CN 中进入 **插件市场 → 技能 → 上传技能**。
2. 上传 `dist/xjtlu-major-advisor-traework-0.1.1-rc1.zip`。此 ZIP 根目录直接放 `SKILL.md`、`references/`、`assets/`，不要再套一层同名目录；上传窗口确认后检查“已安装”中技能是否启用。
3. 在与技能安装环境一致的本地任务中，输入 `/` 选择技能，或直接发送：**请用 xjtlu-major-advisor 技能，开始选专业咨询。**
4. 按一问一答完成咨询；报告生成后，从原任务的产物区查看。也可以要求完整 Markdown 正文。

上述根级 `SKILL.md`、ZIP / `.skill` 格式、YAML 名称和描述、上传与调用方式，已读取[TraeWork 官方技能正文](https://docs.trae.cn/work_skills)。文档区分本地技能与云端技能的生效范围；在本地安装并不证明云端任务也已获得同一包。

## 文件能力与替代入口

[TraeWork 产物空间](https://docs.trae.cn/work_my-space)说明本地与云端产物的预览和管理入口。对本包的报告生成、中文内容、下载与完整档案读取还没有实际运行证据。生成报告后应打开文件核对内容；“发起新对话”不保证继承原任务全部上下文，继续咨询时使用摘要并重新确认资料版本。

若技能上传入口不可用，可把完整 `xjtlu-major-advisor/` 核心目录放进自己的本地任务资料目录，使用[兼容启动词](启动词.md)。有读文件能力才能按目录引用工作；若只能上传附件，则使用[豆包兼容资料](../doubao/README.md)的分组方式。不能把兼容聊天当作原生安装实测。

原任务书中的 [TRAE 国际站 IDE 文档](https://docs.trae.ai/ide/skills)本次返回空正文，不用于证明 TraeWork CN 安装步骤。这里使用的是已完整读取的中国站 **TraeWork** 文档。账户可用模型、额度、技能入口与组织策略仍以实际账户界面为准，本包不绑定某个模型。

## 首次验收

按[平台核验记录](../../validation/platforms.md)完成 P01–P09。记录产品显示名、版本、安装环境、本地/云端模式以及具体结果。安装后若只看到技能名，尚不足以证明它读取了 `references/majors/` 的专业档案。

## 三份 Word 输出

默认交付三个独立 `.docx`：①决策结论与适配候选；②你的选择画像与两个重点候选的差异；③就业探索、接下来的验证行动与信息边界。需要当前平台实际具备 Word 生成及下载能力。不能生成附件时说明限制并保留三组完整正文，不把聊天文本或改后缀文件称为 Word。三份 Word 的目标客户端输出仍需实测。
