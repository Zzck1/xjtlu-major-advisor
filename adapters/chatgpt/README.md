# ChatGPT 使用说明

资料版本：0.1.2-rc1｜核验日期：2026-09-18｜状态：仅文档核验；插件安装、账号入口与完整咨询待用户环境验证。

## 选择入口

OpenAI 官方文档区分独立技能与插件：独立技能可用于桌面应用等本地入口；技能封装在插件内可用于支持的 ChatGPT Chat / Work 入口。技能含 `SKILL.md` 和参考资料，可显式选择或按任务触发。依据[OpenAI Docs：Build skills](https://learn.chatgpt.com/docs/build-skills)。不要推断所有账号、移动端、网页端都有本地 ZIP 导入按钮。

本次提供 `dist/xjtlu-major-advisor-chatgpt-plugin-0.1.2-rc1.zip`，用于受支持的本地插件开发和测试。插件内部含 `.codex-plugin/plugin.json` 兼容清单及 `skills/xjtlu-major-advisor/` 完整核心，采用 OpenAI 官方继续支持的兼容布局。本次只生成待导入分发包，没有写入个人 marketplace、安装插件或发布。该包**尚未发布到公共插件目录**，普通聊天附件上传不会自动安装插件。

## 桌面本地入口

适用条件：当前 ChatGPT 桌面环境可以访问本地资料目录、使用本地插件来源，并且账户/组织策略允许安装。若不具备，使用下面的聊天兼容入口。

1. 解压插件包到自己的资料目录，保留所有子目录。
2. 依照[OpenAI 官方本地插件安装说明](https://developers.openai.com/plugins/build/plugins)将解压后的插件目录登记到自己的本地 marketplace；路径指向包含插件清单及 `skills/` 的目录。可在本地任务中使用系统 `@plugin-creator`（Codex 为 `$plugin-creator`）处理该登记，明确要求保留已有 marketplace 条目，安装在个人环境，不公开发布。
3. 重新打开或刷新当前客户端，从 **Plugins Directory → Personal / 本地来源**找到并安装该插件。开启一个新对话，输入 `@` 选择本技能，再输入：**开始选专业咨询**。
4. 首轮应检查资料并只问一个主要问题；相关专业完整档案读不到时先补资料。

本地 marketplace 与公共目录属于不同分发入口，各客户端可用性可能不同。正式用户安装步骤以[官方 Plugins 说明](https://learn.chatgpt.com/docs/plugins)及当前界面为准。此包仅含技能资料，不需要 MCP 连接或 API Key；不应为了它配置开发者 API 服务。

## 网页、移动端或没有插件入口时

使用[聊天兼容启动词](启动词.md)和[分组上传资料](../doubao/README.md)。先上传核心规则与全专业简表，形成候选后补对应详细档案。上传资料是否全部进入上下文必须逐项抽查，不能凭“已读完”判断。此方式是聊天兼容咨询，不等于原生技能已安装。

不能确认任何专业选择资格时，仍能了解兴趣和能力，但只能输出条件性候选分析。报告支持实际下载才给附件；否则给完整可复制正文。涉及本地路径的核心引用只有宿主实际能读文件时才有效。

## 账号条件和待验收事项

官方说明工作空间技能、本地文件系统技能和插件分别具有分发与权限边界，参见[Skill controls](https://learn.chatgpt.com/docs/enterprise/skills)。本次没有核实当前学生账号套餐、组织权限或所用客户端版本；未获得足以列出各套餐统一可用矩阵的依据。**本包可用的必要条件是当前账号实际提供所选入口与足够模型额度**，不是购买指定套餐。

本次未登录 ChatGPT 学生环境、未导入或发布插件。按照[官方完整插件测试流程](https://developers.openai.com/plugins/deploy/connect-chatgpt)在安装后新建对话，执行[平台检查 P01–P09](../../validation/platforms.md)，其中对专业详情读取、资格边界、逐题等待、长对话保持与报告完整性必须分别记录。

## 三份 Word 输出

默认交付三个独立 `.docx`：①决策结论与适配候选；②你的选择画像与两个重点候选的差异；③就业探索、接下来的验证行动与信息边界。需要当前平台实际具备 Word 生成及下载能力。不能生成附件时说明限制并保留三组完整正文，不把聊天文本或改后缀文件称为 Word。三份 Word 的目标客户端输出仍需实测。
