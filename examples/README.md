## 内容自审记录

- 报告 A：汉字计数 2462；去除 URL 后非空白字符 3248；7 个编号主部分；无模板占位符。报告 B：汉字计数 2569；去除 URL 后非空白字符 3262；7 个编号主部分；无模板占位符。计数包含标题与表格正文，汉字计数使用 Unicode CJK Unified Ideographs 范围。
- 两报告的学校课程名、年级及性质逐项对照本地完整档案；传播学方向和选修没有拼成人人必修；未用专业名称替代实际课程比较。
- 两例均明确所有参与比较的真实专业为 `pending_verification`；没有任何 `confirmed_eligible` 或 `confirmed_ineligible` 判定，没有正式名次或当前首选。
- 报告 A 的工具、调试、数学、英文、跑步记录、硬件、目标及时间安排分别对应 A05–A14；A15 明确纠正模型能力推断。八小时探索安排等于学生两周每周四小时，数学自愿补足另算。
- 报告 B 只使用 A01–A05。数学水平、英文、职业、读研、预算、地点及长期兴趣明确保留未知；A05 急停之后没有再要求画像确认。
- 会话 A 顾问每次只有一个主要问题，画像确认一次；会话 B 跳过 A01 已提供的年份与身份，急停后直接报告。此结论来自文本自审，不是模型对话运行测得。
- 来源日期与范围分别保留：学校专业页当前招生时间显示 2027 年 9 月，未用它代替 2026 届培养方案；S02 只用于 2026/27 内地新生宏观规则；BLS 只作美国职业结构参考；UCL 2027/28 仅为先修要求示例。

阅读这些例子不会确认任何真实学生的选择资格。后续动态执行测试应另留实际输入、输出和测试环境记录，不把本文件当作运行日志。
