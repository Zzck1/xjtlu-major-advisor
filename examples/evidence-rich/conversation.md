# 虚构示例 A：兴趣证据充分，个人选择资格待核实

版本：0.1.0-rc1｜编写日期：2026-09-18。

**这是开发者编写的完整示例，不是真实学生记录、平台实测或独立模型运行结果。** 学生经历全部虚构；学校事实来自同版本专业档案及原始链接。问答展示预期交互，A01–A15 是本示例内部证据编号，不构成成绩或身份核验。

## 开始与逐题问答

**顾问：**我们按一问一答了解你的情况，通常约 15–25 分钟，最后给出候选比较、依据和验证行动；你可以随时跳过或要求先出报告。本示例使用 0.1.0-rc1 的专业目录、资格边界与详细档案。你是哪一年入学西浦的？

**学生 A01：**2026 年，刚入学。

**顾问：**你的入学身份属于哪一类？

**学生 A02：**中国内地普通高考录取。

**顾问：**你已经在考虑哪些专业？

**学生 A03：**计算机科学与技术、信息与计算科学、数据科学与大数据技术，都想了解，还没有定顺序。

**顾问：**你目前判断自己可以选择这些专业的依据是什么？

**学生 A04：**听同学说大一可以自由选，但我没看过校内政策。我才刚开始第一学期，没有大学期末成绩。

**顾问：**现有招生章程保留了指定课程或成绩条件，所以先把三个专业的个人资格记为待核实。最近一次你主动投入的技术活动是什么？

**学生 A05：**暑假自己用 Python 做了一个小记账程序，读取 CSV，按类别统计每月支出，给家人试了一下。我最喜欢让别人能用上、少做重复计算的部分。没有做过很大的应用。

**顾问：**做这个程序时，哪一个困难让你花了最多时间？

**学生 A06：**不同日期格式导致统计出错。我用了两个晚上打印中间结果查错，最后修好了。修复时挺烦，但看到结果对了会愿意继续改。

**顾问：**你现在的数学学习情况怎样？

**学生 A07：**高中函数和概率题还可以，严格证明不熟。大学课才开始，我没法报成绩。如果需要，每周愿意用三小时补基础，不是想完全避开数学。

**顾问：**你读英文技术材料的实际体验怎样？

**学生 A08：**做程序时看过英文文档，生词会查，能按示例操作。把过程写成英文说明还比较慢，中文能讲清楚。

**顾问：**除了把程序做出来，你对分析数据本身有什么体验？

**学生 A09：**我整理过自己跑步记录，改掉几条格式不统一的数据，画了里程图。我喜欢看规律，但还没学模型，不知道会不会喜欢统计推导。

**顾问：**这几个领域里，哪类任务目前最让你犹豫？

**学生 A10：**高中电路题我比较吃力，也不觉得有意思。不过没做过大学硬件项目，不能确定是不是一直不喜欢。

**顾问：**你希望未来工作中经常做什么？

**学生 A11：**希望做有实际用途的软件，或者用数据帮人做决定，还没定岗位。不太想整天只做重复录入。我在意能学到东西，也希望工作稳定，但没有指定收入目标。

**顾问：**你对读研有什么想法？

**学生 A12：**可能读，英国或香港都愿意了解，还没决定学校和方向，也没认真算预算。

**顾问：**你目前有什么会影响专业探索的现实安排？

**学生 A13：**苏州园区和太仓我都可以考虑，不过还没了解具体安排。接下来两周可以每周花四小时做探索任务，数学补习那三小时另算。预算目前没信息可补。

**顾问：**在这些取舍中，你最看重什么？

**学生 A14：**第一是日常任务让我愿意持续投入，然后是能积累以后求职或读研用得上的能力。我不想只追热门，也没打算选工资听起来最高的。

## 一次画像确认

**顾问：**目前我理解：你有小型 Python 工具和数据整理经历，愿意调试；喜欢实际用途，对数据规律好奇，但尚未体验模型推导。数学证明、英文写作和硬件体验仍需补证据；未来可能做软件或数据相关工作，读研、预算未定。你最重视能持续投入的日常任务。三个专业的个人选择资格和本届课程条件都待核实。这个理解有需要纠正的地方吗？

**学生 A15：**基本正确。特别是别把我说成已经擅长机器学习，我只是做过简单统计图。

**顾问：**已记录：数据模型能力未知，不能从画图经历推断机器学习水平。下面生成不分名次的适配候选报告，先给验证计划，等获得适用政策后再更新资格。
